# Housekeeping: Makefile, working tree, dependencies, dead code

## Summary

Small items, each visible during a review. Found during the audit in
`claude/reports/report_3_20260929-041535.md` (section 6.8).

## Details

- **Working tree must not be submitted as is.** `src/__main__.py` has the visualiser call
  commented out, and `make lint` fails on it (`F401 Visualiser imported but unused`, `E501` at
  line 58). The `turns[1:]` change in `print_turns` is a fix worth keeping (see issue_3).
- **`Makefile:56`**: `.phony` must be uppercase `.PHONY`; as written no target is phony, so a
  file named `clean`, `run` or `install` would silence the target.
- **`Makefile:43`**: `mypy src ...`. The subject specifies `mypy . --warn-return-any
  --warn-unused-ignores --ignore-missing-imports --disallow-untyped-defs --check-untyped-defs`.
  (It passes today on `.` too.)
- **`Makefile:39`**: `--exclude=$(VENV),llm_sdk` mentions a directory from another project.
  **`Makefile:32`**: `$(TEST_NAME)` is never defined.
- **Unused dependencies**: `matplotlib`, `pydantic`. `black`, `flake8`, `mypy` could be a dev
  dependency group.
- **Dead code**: `src/graph/`, `src/solver/`, `src/display/`, `src/visualiser/color_palette.py`,
  `Visualiser.__init__`'s `color_palette` parameter (also a mutable default `{}`),
  `Simulation.bfs`'s `visited` parameter, `Drone.name` (unused, see issue_3),
  `Node.__lt__` (the heap never compares nodes because `insertion_idx` breaks ties).
- **`Main`** catches `InvalidMoveError` around `check_solvable`, which cannot raise it
  (issue_1).
- **Asserts as validation** in the parser (`parser.py:180, 185, 194`), converted to
  `ParsingError` by an `except AssertionError`. They disappear under `python -O`. Low risk.
